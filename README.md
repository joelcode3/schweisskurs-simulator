# Schweißkurs mit Dennis

Mini-Game im Browser: Bau in der Werkstatt einen Ofen aus einer alten Gasflasche.
Mach keinen Mist, sonst kommt Dennis.

- Läuft auf Computer und Handy, ohne Installation (GitHub Pages).
- Ich-Perspektive im Comic-Stil, Minispiele für Flex, Schweißen und Schlacke.
- Dennis-Wutanzeige, echte Dennis-Clips (siehe `clips/LIESMICH.md`), Note am Ende.

Lokal starten: `python3 -m http.server` und dann http://localhost:8000 öffnen.

Nur für Kumpels. Dennis ist einverstanden.
